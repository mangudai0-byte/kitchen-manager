# 키친매니저

오션메이드 직원들이 함께 쓰는 업무 앱입니다. 예전 **오션메이드 척척박사**(필름·도어 견적, 단가표, 재고)와 **가구공사 마진계산기**를 하나로 합쳤습니다.

접속 주소: https://mangudai0-byte.github.io/kitchen-manager/

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 필름 견적서 | 예림 필름 단가 기준 견적, 롤/절단 자동계산, 견적서 이미지 저장 |
| 생산도어 견적서 | 예림·한솔 생산도어 발주 견적, A/B등급 |
| 공사 마진 | PB 소요량 자동계산, 비용 6개 항목, 순마진·이익률, 현장 목록, 업체별 분석 |
| 필름 단가표 | 예림 인테리어필름 단가표, 공유용 이미지 |
| 생산도어 단가표 | 예림·한솔 단가표, 공유용 이미지 |
| 재고 관리 | 필름 입고·출고, 재고 이력, 재고 부족 표시 |
| 데이터 | 견적 기록(필름·도어), 재고 통계, 내 정보, 기존 데이터 가져오기 |

모든 데이터는 구글 스프레드시트 하나에 모여 모든 직원이 함께 봅니다. 저장할 때 직원 이름이 함께 기록되고, 화면은 1분마다 자동으로 새로 불러옵니다.

## 직원이 처음 쓰는 방법

1. 위 접속 주소를 엽니다.
2. 팀 코드와 이름을 넣고 **시작하기**를 누릅니다.
3. 휴대폰은 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

한 번 들어오면 그 기기에서는 다시 입력하지 않아도 됩니다.

## 관리자 설정

### 스프레드시트 스크립트 업데이트

마진계산기 때 만든 스프레드시트를 그대로 이어서 씁니다. 기존 현장 데이터는 유지됩니다.

1. 스프레드시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 편집기 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs)를 통째로 붙여 넣습니다.
3. 맨 위 `TEAM_CODE`의 따옴표 안에 팀 코드를 다시 적고 저장합니다.
4. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 누릅니다. 웹 앱 주소는 그대로 유지됩니다.

스프레드시트에 `재고`, `재고이력`, `견적기록`, `공유값` 시트가 자동으로 생깁니다. `재고` 시트의 잔량이나 `설정` 시트의 PB 단가는 시트에서 직접 고쳐도 앱에 반영됩니다. 각 시트 맨 오른쪽 `원본데이터` 열과 `공유값` 시트는 고치지 마세요.

### 기존 데이터 옮기기 (한 번만)

앱의 **데이터** 탭 맨 아래 **기존 데이터 가져오기**에서 합니다.

- **척척박사 재고·재고 이력**: 예전 척척박사 서버에 있던 공용 재고입니다. 한 사람만 누르면 됩니다.
- **이 기기의 척척박사 거래처·견적 기록**: 척척박사는 거래처와 견적 기록을 기기마다 따로 저장했습니다. 척척박사를 쓰던 기기에서 각각 한 번씩 눌러 주세요.
- **이 기기의 마진계산기 현장**: 마진계산기를 공용 저장소 없이 쓰던 기기에서 누르면 됩니다.

이미 있는 항목은 건너뛰므로 여러 번 눌러도 중복되지 않습니다.

### 주의

- **실제 팀 코드는 GitHub에 올리지 마세요.** 이 저장소는 공개라서 누구나 파일을 볼 수 있습니다. 팀 코드는 Apps Script 편집기에만 적습니다.
- 팀 코드를 아는 사람은 데이터를 보고, 고치고, 지울 수 있습니다. 퇴사자가 생기면 팀 코드를 바꾸고 새 버전으로 배포하세요. 그러면 모든 기기에 새 팀 코드를 묻는 화면이 나옵니다.
- 실수로 지운 내용은 스프레드시트의 **파일 → 버전 기록**에서 되살릴 수 있습니다.
- 스크립트를 새로 배포해서 웹 앱 주소가 바뀌면 `index.html`의 `KM_URL`도 바꿔야 합니다.
