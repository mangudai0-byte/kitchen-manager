# 키친매니저

오션메이드 직원들이 함께 쓰는 업무 앱입니다. 예전 **오션메이드 척척박사**(필름·도어 견적, 단가표, 재고)와 **가구공사 마진계산기**를 하나로 합쳤습니다.

접속 주소: https://mangudai0-byte.github.io/kitchen-manager/

## 화면 구성

앱을 열면 첫 화면에서 업무를 고릅니다. 들어가면 아래쪽에 그 업무의 메뉴만 보이고, **홈** 버튼으로 첫 화면에 돌아옵니다.

| 업무 | 아래 메뉴 | 하는 일 |
|---|---|---|
| 공사 마진 | 계산 · 현장 목록 · 업체별 분석 | PB 소요량 자동계산, 비용 6개 항목, 순마진·이익률 |
| 필름 | 필름 견적서 · 필름 단가표 · 재고 관리 · 데이터 | 예림 필름 견적과 견적서 이미지, 단가표, 입고·출고, 견적 기록과 재고 통계 |
| 생산도어 | 생산도어 견적서 · 생산도어 단가표 | 예림·한솔 생산도어 발주 견적, A/B등급 단가표 |

첫 화면에는 이번 달 현장·견적 건수와 재고 부족 색상 수가 함께 보이고, 아래 **내 정보**에서 이름 변경과 로그아웃을 합니다.

모든 데이터는 구글 스프레드시트 하나에 모여 모든 직원이 함께 봅니다. 저장할 때 직원 이름이 함께 기록되고, 화면은 1분마다 자동으로 새로 불러옵니다.

## 직원이 처음 쓰는 방법

1. 위 접속 주소를 엽니다.
2. 관리자에게 받은 **이름과 비밀번호**를 넣고 **시작하기**를 누릅니다.
3. 휴대폰은 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

한 번 들어오면 그 기기에서는 다시 입력하지 않아도 됩니다.

## 관리자 설정

### 직원 등록 (직원 시트)

스프레드시트의 **직원** 시트에 한 사람당 한 줄씩 적습니다.

| 이름 | 비밀번호 | 메모 | 회사 | 권한 |
|---|---|---|---|---|
| 정근도 | (본인이 정한 비밀번호) | 대표 | 오션메이드 | 관리자 |
| 김대리 | (김대리 비밀번호) | | 오션메이드 | |
| 박과장 | (박과장 비밀번호) | | 한빛인테리어 | |

- **직원 추가**: 줄을 추가하면 바로 로그인할 수 있습니다.
- **퇴사·차단**: 그 줄을 지우면 1분 안에 그 사람 앱이 로그인 화면으로 돌아갑니다. 다른 직원은 아무것도 바꿀 필요가 없습니다.
- **비밀번호 변경**: B열을 고치면 됩니다.
- 저장한 사람 이름은 로그인한 이름으로 기록됩니다.
- **공사 마진은 회사별로 나뉩니다.** 직원은 D열 회사의 현장만 보고 저장합니다. E열에 `관리자`라고 적은 사람은 모든 회사 현장을 보고, 공사 마진 화면 위에서 회사를 골라 볼 수 있습니다.
- PB 단가도 회사별로 따로 저장됩니다.
- 현장마다 **담당자**를 그 회사 직원 중에서 고릅니다. **담당자** 메뉴에서 기간별 담당자 실적(현장 수, 공사금액, 순마진, 이익률)을 비교합니다.
- **필름·생산도어는 오션메이드 직원과 관리자만** 씁니다. 다른 회사 직원에게는 메뉴가 보이지 않고, 재고·견적 기록·거래처 데이터도 보내지 않습니다. 이 회사 이름은 Code.gs 맨 위 `FILM_ORG`에 있습니다.
- 이 스프레드시트에는 비밀번호가 적혀 있으니 **직원에게 시트 편집 권한을 공유하지 마세요.**

### 스프레드시트 스크립트 업데이트

1. 스프레드시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 편집기 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs)를 통째로 붙여 넣고 저장합니다. 고칠 곳은 없습니다.
3. **배포 → 배포 관리**에서 앱이 쓰는 배포(주소가 `AKfycbyn…`로 시작)를 고르고 **연필(수정) → 버전: 새 버전 → 배포**를 누릅니다. 웹 앱 주소는 그대로 유지됩니다.

`직원`, `재고`, `재고이력`, `견적기록`, `공유값` 시트는 처음 접속할 때 자동으로 생깁니다. `재고` 시트의 잔량이나 `설정` 시트의 PB 단가는 시트에서 직접 고쳐도 앱에 반영됩니다. 각 시트 맨 오른쪽 `원본데이터` 열과 `공유값` 시트는 고치지 마세요.

### 기존 데이터 옮기기 (한 번만)

앱의 **필름 → 데이터** 화면 맨 아래 **기존 데이터 가져오기**에서 합니다.

- **척척박사 재고·재고 이력**: 예전 척척박사 서버에 있던 공용 재고입니다. 한 사람만 누르면 됩니다.
- **이 기기의 척척박사 거래처·견적 기록**: 척척박사는 거래처와 견적 기록을 기기마다 따로 저장했습니다. 척척박사를 쓰던 기기에서 각각 한 번씩 눌러 주세요.
- **이 기기의 마진계산기 현장**: 마진계산기를 공용 저장소 없이 쓰던 기기에서 누르면 됩니다.

이미 있는 항목은 건너뛰므로 여러 번 눌러도 중복되지 않습니다.

### 주의

- 실수로 지운 내용은 스프레드시트의 **파일 → 버전 기록**에서 되살릴 수 있습니다.
- 스크립트를 **새 배포**로 올리면 웹 앱 주소가 바뀝니다. 꼭 **배포 관리 → 수정**으로 올리세요. 주소가 바뀌었다면 `index.html`의 `KM_URL`도 바꿔야 합니다.
